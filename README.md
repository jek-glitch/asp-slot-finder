# ASP Slot Finder — PWA

Веб-версия вашего расширения ASP Exam Slot Finder. Работает как обычный сайт,
который можно добавить на рабочий стол компьютера и на iPhone, с push-уведомлениями.

## Почему нужен headless-браузер

`https://eservicii.gov.md/asp/dimtcca/cerere/*` — это Angular SPA: сервер
отдаёт пустой каркас, а календарь дорисовывается в браузере через JS. Обычный
`fetch()` на сервере такой скрапинг не покажет. Поэтому `api/check.js`
запускает настоящий headless Chromium (`@sparticuz/chromium` + `puppeteer-core`,
работает в serverless-функции на Vercel) и сканирует календарь так же, как это
делал ваш `content.js`.

## Архитектура

```
cron-job.org (раз в 5–10 мин, бесплатно)
        │  GET /api/check  (заголовок X-Cron-Secret)
        v
Vercel Serverless Function (api/check.js)
        │  запускает headless Chromium, открывает форму ASP,
        │  листает месяцы, ищет самую раннюю дату
        v
Upstash Redis (бесплатный тариф)
        │  хранит профили, лучшую найденную дату, историю, push-подписки
        v
web-push → Push-уведомление в браузер / на iPhone (PWA на главном экране)
```

## Шаг 1. Upstash Redis

1. Зарегистрируйтесь на upstash.com, создайте Redis-базу (Region — ближе к
   Vercel-региону деплоя).
2. Скопируйте `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`.

## Шаг 2. VAPID-ключи для push-уведомлений

Локально (нужен Node.js):

```bash
npx web-push generate-vapid-keys
```

Сохраните `Public Key` и `Private Key`.

## Шаг 3. Деплой на Vercel

1. Загрузите эту папку в новый репозиторий на GitHub (или используйте
   `vercel --prod` из папки проекта через Vercel CLI).
2. На vercel.com → New Project → импортируйте репозиторий.
3. В Settings → Environment Variables добавьте:
   - `UPSTASH_REDIS_REST_URL`
   - `UPSTASH_REDIS_REST_TOKEN`
   - `VAPID_PUBLIC_KEY`
   - `VAPID_PRIVATE_KEY`
   - `VAPID_EMAIL` — любой ваш email (нужен по спецификации push)
   - `CRON_SECRET` — придумайте случайную строку, например `openssl rand -hex 16`
4. Deploy. Домен будет вида `https://your-app.vercel.app`.

> Хостинг Vercel Hobby даёт функциям до 60 сек выполнения (указано в
> `vercel.json`) — этого достаточно на запуск Chromium и сканирование
> нескольких месяцев календаря.

## Шаг 4. cron-job.org — фоновая проверка

Vercel Cron на бесплатном плане запускается не чаще раза в день, поэтому
внешний планировщик обязателен:

1. Зарегистрируйтесь на cron-job.org (бесплатно).
2. Создайте job:
   - URL: `https://your-app.vercel.app/api/check`
   - Метод: `GET`
   - Interval: каждые 5–10 минут
   - Headers: `X-Cron-Secret: <значение CRON_SECRET>`
3. Сохраните и включите job.

## Шаг 5. Открыть сайт и настроить

1. Откройте `https://your-app.vercel.app`.
2. Нажмите «Включить уведомления» → разрешите.
3. Добавьте профиль: имя + ссылка вида
   `https://eservicii.gov.md/asp/dimtcca/cerere/apo01`.
4. Нажмите «Подписаться на этот профиль» рядом с ним (подписка привязывается
   к конкретному профилю, чтобы уведомления приходили именно по нему).

## Шаг 6. Установка на iPhone (Safari)

1. Откройте сайт в Safari на iPhone.
2. Поделиться (значок ⬆️) → «На экран «Домой»».
3. **Важно (ограничение iOS):** веб-push на iPhone работает только если сайт
   добавлен на главный экран и требует **iOS 16.4+**. После добавления
   откройте приложение именно с главного экрана (не из Safari) один раз и
   разрешите уведомления — иначе подписка не активируется.

## Как это работает дальше

- cron-job.org каждые 5–10 минут дергает `/api/check`.
- Функция открывает headless-браузер, для каждого профиля сканирует
  календарь ASP (как ваш content.js), находит самую раннюю свободную дату.
- Если дата раньше уже сохранённой лучшей — она сохраняется в Redis,
  добавляется в историю и рассылается push-уведомление всем подписчикам
  этого профиля.
- На сайте всегда видна лучшая найденная дата и последние 5 записей истории.

## Ограничения бесплатных тарифов

- **cron-job.org**: минимальный интервал на бесплатном плане — 1 минуту,
  так что 5–10 минут спокойно укладывается.
- **Upstash Redis free tier**: 10 000 команд/день — при проверке раз в
  5 минут (288 раз/день) и нескольких профилях этого с запасом хватает.
- **Vercel Hobby**: ограничение на функцию — 60 сек выполнения (уже
  выставлено в `vercel.json`) и месячный лимит серверных вычислений
  (compute hours); при 1–3 профилях и проверке раз в 5–10 минут в лимит
  Hobby-плана укладывается.
